# Checklist: Accessibilità

- [ ] Navigazione completa da tastiera; focus visibile ovunque
- [ ] Skip link presente e funzionante
- [ ] Contrasto: testo ≥ 4.5:1, UI ≥ 3:1 (verificato, non a occhio)
- [ ] Label associate a ogni campo; errori annunciati (aria-describedby)
- [ ] Heading gerarchici; landmark semantici
- [ ] Alt text sensati; decorative con alt=""
- [ ] prefers-reduced-motion rispettato
- [ ] Zoom 200% senza perdita di contenuto
- [ ] Modali/accordion: aria corretti, Esc, focus management
- [ ] Ordine di lettura logico (DOM = senso)
