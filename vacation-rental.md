# Playbook: E-commerce (vetrina + conversione)

## Fase 0 — Contesto
- [ ] brain/products.md; piattaforma (Shopify? headless? WooCommerce?)
- [ ] Margini e AOV: definiscono quanto attrito è accettabile

## Fase 1 — Pagina prodotto (la vera landing)
- [ ] Above the fold: gallery, titolo beneficio, prezzo, disponibilità, CTA, trust
      (spedizione, resi, pagamenti)
- [ ] Descrizione: benefici → dettagli → specifiche (in quest'ordine)
- [ ] Recensioni con foto se esistono; Q&A per obiezioni
- [ ] JSON-LD Product completo (price, availability, rating) → rich results

## Fase 2 — Riduzione abbandono
- [ ] Costi di spedizione visibili PRIMA del checkout
- [ ] Checkout: guest checkout obbligatorio, meno campi possibile
- [ ] Trust badge reali (pagamenti, resi), niente sigilli inventati

## Fase 3 — Cataloghi e SEO
- [ ] Categorie con testo utile (non SEO-spam), filtri crawlabili con criterio
- [ ] Immagini prodotto: nomi file e alt sensati, WebP/AVIF, zoom

## Fase 4 — Self-review
- [ ] Checklist standard + "comprerei da questo sito con la mia carta?"
