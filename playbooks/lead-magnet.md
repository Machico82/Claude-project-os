# Playbook: Lead Magnet + Squeeze page

## Fase 0 — Scelta del magnet
- [ ] Da brain/avatar.md: quale problema URGENTE risolve in < 15 minuti d'uso?
- [ ] Formati che convertono: checklist, template, calcolatore, mini-guida specifica
- [ ] Test: "pagherebbe 10€ per questo?" Se no, non è abbastanza buono per un'email

## Fase 1 — Squeeze page
- [ ] Una pagina, zero navigazione: headline (risultato) + 3 bullet (cosa ottieni)
      + mockup del magnet + form (solo email) + privacy microcopy
- [ ] Sopra la fold TUTTO; sotto solo eventuale prova sociale

## Fase 2 — Delivery
- [ ] Thank-you page: consegna immediata + "controlla lo spam" + secondo step
      (l'offerta o un contenuto ponte)
- [ ] Email di consegna automatica; il file ha un nome professionale

## Fase 3 — Il magnet stesso
- [ ] Se PDF/checklist: brandizzato (brand/), azionabile, con CTA finale al servizio
- [ ] Se calcolatore/tool: vedi references/frontend.md, risultato condivisibile

## Fase 4 — Follow-up (nota per l'utente)
- [ ] Suggerisci sequenza email 3-5 messaggi: consegna → valore → caso studio → offerta

## Fase 5 — Self-review
- [ ] Conversione attesa squeeze: 25-40%. La pagina è abbastanza focalizzata per quei numeri?
