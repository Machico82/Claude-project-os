# Checklist: Conversione (CRO)

## Above the fold
- [ ] Test 5 secondi: cosa, per chi, perché — chiaro?
- [ ] CTA primaria visibile senza scroll, colore dominante unico
- [ ] Elemento di fiducia immediato (rating/loghi/numeri) presente
- [ ] Visual pertinente (prodotto/risultato), non stock generica

## Struttura
- [ ] Una sola azione di conversione per pagina
- [ ] CTA identica ripetuta ogni ~2 schermate
- [ ] Ogni sezione risponde a una domanda reale del cliente
- [ ] FAQ include le obiezioni scomode (prezzo, rischio, tempo)
- [ ] Nessuna via di fuga inutile (nav ridotta su landing pure)

## Copy
- [ ] Zero frasi vaghe/vietate (brand/voice.md)
- [ ] Benefici nei titoli, prove nei testi, numeri specifici
- [ ] Parla al "tu", con le parole di brain/avatar.md
- [ ] Microcopy anti-obiezione sotto le CTA

## Fiducia
- [ ] Social proof SOLO reale (brain/customers.md); nessun dato inventato
- [ ] Garanzia/riduzione rischio visibile vicino alla CTA
- [ ] Contatti reali, P.IVA, privacy nel footer
- [ ] Zero dark pattern (countdown finti, scarcity inventata)

## Post-conversione
- [ ] Thank-you page con conferma + prossimo step
- [ ] Evento di conversione tracciato
