# Checklist: SEO

- [ ] 1 solo h1, gerarchia heading corretta
- [ ] Title ≤ 60 char con keyword; description ≤ 155 con CTA
- [ ] Canonical presente; nessun contenuto duplicato
- [ ] JSON-LD valido (testato) e pertinente al tipo di pagina
- [ ] OG + Twitter card completi; og:image 1200×630 dedicata
- [ ] Sitemap.xml e robots.txt corretti
- [ ] URL puliti; redirect 301 per URL cambiati
- [ ] Alt text su tutte le immagini contenutistiche
- [ ] Link interni con anchor descrittive; nessun link rotto
- [ ] Contenuto renderizzato senza JS (view-source lo mostra)
- [ ] Nessun testo essenziale dentro immagini
